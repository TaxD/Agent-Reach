# 세션과 전용 브라우저

사용자가 로그인·로그아웃·계정 전환을 요청하거나, 결과가 `NEED_LOGIN`일 때 읽습니다. 로그인이 관련된 채널은 `reddit`과 `twitter`뿐입니다.

## 구조

- 전용 프로필(`~/.agent-reach/browser/profile`) 하나를 두 채널이 함께 사용하며, 사용자의 평소 Chrome 프로필과 분리되어 있습니다. 프로그램은 사용자의 평소 브라우저를 건드리지 않습니다.
- 엔진은 이 컴퓨터에 설치된 Google Chrome입니다. 브라우저를 내려받지 않습니다. macOS와 Linux에서만 지원합니다.
- **창이 있는 일반 Chrome으로 실행됩니다**(헤드리스가 아님). 다만 조회용 탭은 앞으로 나오지 않게 열리므로, 창이 다른 창 뒤에 있을 수 있습니다. Agent Reach 명령이 10분간 없으면 닫히고, 다음 조회 때 다시 열립니다. 웹 페이지의 동작은 이 시간을 연장하지 못합니다. 로그인은 창이 열린 뒤 10분 안에 마쳐야 합니다.
- **Chrome은 네트워크 포트를 열지 않습니다.** 실행한 프로세스만 쓸 수 있는 파이프로 제어되고, 디버깅 포트가 없습니다. 열리는 포트는 OpenCLI 데몬의 `127.0.0.1:19825`와 `[::1]:19825`뿐이며, 이 포트는 서명된 요청만 받아들입니다.
- 쿠키는 Chrome 프로필에 저장됩니다. 쿠키를 파일로 내보내거나 다른 브라우저에서 가져오는 기능이 없습니다.
- 사이트 조회는 OpenCLI의 보안 강화 포크(github.com/TaxD/OpenCLI)가 수행합니다. 이 포크의 로컬 데몬은 이 컴퓨터의 비밀 토큰으로 서명된 요청만 받아들이고 응답에도 서명하므로, 다른 사용자의 프로그램이 데몬을 통해 브라우저를 조종하거나 데몬 행세를 할 수 없습니다. 데몬은 감시 프로세스가 전용 브라우저와 함께 띄우고 함께 종료합니다. 감시 프로세스가 비정상 종료되면 데몬이 남을 수 있으며, 다음 실행 때 정리됩니다.
- OpenCLI와 확장 프로그램은 버전과 해시가 고정된 릴리스로만 설치되고, 확장 프로그램 파일은 브라우저를 열 때마다 다시 검증됩니다.
- 동시 실행: 같은 플랫폼은 최대 2건, 전체는 최대 4건이며, 초과분은 최대 2분간 대기한 뒤 `BUSY`를 반환합니다. 같은 플랫폼의 검색은 최소 10초 간격을 둡니다.

## 켜기

1. 사용자가 로그인 기반 조회를 원한다고 말한 경우에만 `agent-reach add <채널>`을 실행합니다. `login`, `logout`, `browser setup`도 켜진 채널이 있어야 동작합니다. Node.js 20.18.1 이상과 Google Chrome이 설치되어 있어야 하며, 없으면 `NEED_SETUP`이 반환되므로 사용자에게 설치를 요청합니다. 프로그램은 Node.js나 Chrome을 내려받지 않습니다.
2. 처음 켤 때 사용자에게 알립니다: 자동화된 조회는 플랫폼 약관에 어긋날 수 있고 계정이 잠길 수 있으므로 보조 계정을 권합니다. OpenCLI에는 자동화 탐지를 줄이는 코드가 원래 포함되어 있습니다.

## 로그인

- 실제로 `NEED_LOGIN`이 반환되었고, 남은 작업에 그 경로가 꼭 필요할 때에만 로그인을 요청합니다.
- `agent-reach login <채널>`이 전용 창에 해당 사이트의 로그인 페이지를 엽니다. 사용자가 직접 로그인합니다. 대신 로그인하지 않고, 비밀번호를 묻지 않고, 쿠키를 출력하지 않습니다.
- 사용자가 로그인을 마치면 원래의 동작을 다시 실행해서 확인합니다.
- `PLATFORM_BLOCKED`(사람 인증 요구)가 나오면 멈춥니다. 사용자가 전용 창에서 직접 처리할 수 있지만, 우회를 시도하지 않습니다.

## 로그아웃과 삭제

- `agent-reach logout <채널>`: 전용 브라우저에서 해당 사이트의 쿠키를 지우고 삭제되었는지 확인합니다. 저장 데이터는 사이트의 주요 주소에 대해서만 지우므로, 완전히 지우려면 `agent-reach uninstall`로 프로필 전체를 삭제합니다. 다른 사이트는 유지됩니다.
- `agent-reach remove <채널>`: 채널을 끄면서 해당 사이트의 로그인도 지웁니다. 정리에 실패하면 채널 기록을 유지하고 오류를 반환하므로 다시 시도할 수 있습니다.
- `agent-reach uninstall`: 전용 프로필 전체를 포함해 프로그램이 만든 것을 지웁니다.
