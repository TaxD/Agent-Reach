# 세션과 전용 브라우저

사용자가 로그인·로그아웃·계정 전환을 요청하거나, 결과가 `NEED_LOGIN`일 때 읽습니다. 로그인이 관련된 채널은 `reddit`과 `twitter`뿐입니다.

## 전용 브라우저

- 브라우저 채널은 전용 프로필(`~/.agent-reach/browser/profile`) 하나를 함께 사용하며, 사용자의 평소 Chrome 프로필과 분리되어 있습니다. 프로그램은 사용자의 평소 브라우저를 닫거나 수정하지 않습니다.
- 엔진은 이 컴퓨터에 설치된 Google Chrome입니다. 별도의 브라우저 바이너리를 내려받지 않으며, 탐지 회피용 브라우저를 사용하지 않습니다.
- `agent-reach add <채널>`은 Node, OpenCLI, 확장 프로그램을 자동으로 준비합니다. 확장 프로그램은 검증된 한 버전으로 고정되어 있고, 내려받은 파일의 SHA-256이 일치할 때에만 설치됩니다. Windows에서는 사용자가 "Chrome에 추가"를 한 번 눌러야 할 수 있습니다.
- 기본은 헤드리스이며 창이 뜨지 않습니다. `agent-reach login <채널>`만 창을 표시합니다. 창이 열려 있는 동안의 조회는 그 창을 그대로 사용하며, 사용자가 로그인을 마쳤다고 할 때까지 기다립니다.
- 10분간 사용하지 않으면 자동으로 닫히고, 다음 호출 때 다시 열립니다.
- 동시 실행: 같은 플랫폼은 최대 2건, 전체는 최대 4건이며, 초과분은 최대 2분간 대기한 뒤 `BUSY`를 반환합니다. 같은 플랫폼의 검색은 최소 10초 간격을 둡니다.
- 전용 브라우저는 `127.0.0.1`의 디버깅 포트(기본 9222)를 엽니다. 이 포트는 같은 컴퓨터의 다른 프로그램도 접근할 수 있으므로, 전용 프로필에는 조회에 필요한 계정만 로그인하도록 사용자에게 안내합니다.

## 다른 브라우저의 로그인 가져오기 (명시적 요청 전용)

1. 일반 조회는 다른 브라우저의 쿠키를 **절대로 자동 복사하지 않습니다.** 전용 프로필에 저장된 세션만 사용합니다.
2. 사용자가 "내 Chrome에 로그인된 것을 가져와 달라"고 명시적으로 요청한 경우에만 `agent-reach login <채널> --import-existing`을 실행합니다. 이 명령은 OpenCLI 확장 프로그램이 연결된 브라우저 프로필에서 **해당 사이트의 쿠키만** 한 번 복사합니다. 브라우저 전체, 다른 사이트, 비밀번호 저장소는 건드리지 않습니다.
3. 여러 브라우저 프로필에 그 사이트의 로그인이 있으면 `agent-reach browser profiles`로 목록을 보여 주고, 사용자가 고른 것을 `agent-reach browser use <ID>`로 지정합니다. 임의로 고르지 않습니다.
4. 가져올 로그인을 찾지 못했거나 Bridge가 실행 중이 아니면 `NEED_SETUP`이 반환되고 저장된 세션은 그대로 유지됩니다.

## 사용자가 직접 로그인해야 할 때

- 실제로 `NEED_LOGIN`이 반환되었고, 남은 작업에 그 경로가 꼭 필요할 때에만 로그인을 요청합니다. 본문 옆에 로그인 버튼이 있는 것만으로는 로그인이 필요하다고 보지 않습니다.
- `agent-reach login <채널>`이 전용 브라우저에서 해당 사이트의 로그인 페이지를 엽니다. 사용자가 직접 로그인합니다. 대신 로그인하지 않고, 비밀번호를 묻지 않고, 쿠키를 출력하지 않습니다.
- 결과의 `next`에 다음 단계가 적혀 있으면 그대로 따릅니다.
- 사용자가 로그인을 마치면 원래의 동작을 다시 실행해서 확인합니다.

## 로그아웃과 삭제

- `agent-reach logout <채널>`: 전용 브라우저에서 해당 사이트의 로그인과 저장 데이터만 지웁니다. 다른 사이트는 유지됩니다.
- `agent-reach remove <채널>`: 채널을 제거하면서 해당 사이트의 로그인과 저장 데이터도 지웁니다. 정리에 실패하면 채널 기록을 유지하고 오류를 반환하므로 다시 시도할 수 있습니다.
