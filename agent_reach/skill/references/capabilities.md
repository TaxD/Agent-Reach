# 기능 범위

사용자가 "무엇을 조회할 수 있는지, 결과가 완전한지"를 묻거나, 결과의 완전성을 판단해야 할 때 읽습니다. 아래 표는 선언된 기능이며, 모든 네트워크·계정·콘텐츠에서 실측된 결과를 뜻하지 않습니다.

## 세 가지 수준

- **공개 경로**: 로그인 없이 공개 API·피드·웹 검색으로 얻는 결과입니다. 대부분의 채널이 여기에 해당합니다.
- **로그인 경로**: `reddit`의 사이트 동작과 `twitter`는 사용자가 `add`로 켜고 전용 브라우저에서 직접 로그인해야 동작합니다. 켜지 않으면 공개 웹 결과만 얻습니다.
- **이 컴퓨터에서 실측됨**: `agent-reach check`가 최근 24시간 안에 통과한 동작만 해당합니다. 설치 성공이나 로그인 저장은 실측 통과를 뜻하지 않습니다.

## 채널별 범위

| 채널 | 얻을 수 있는 것 | 보장하지 않는 것 |
|---|---|---|
| github | 공개 저장소 검색, README, 이슈/PR 본문과 댓글(최대 50개) | 비공개 저장소(토큰이 있어도 읽지 않음), 코드 검색, 전체 댓글 |
| github-trending | 언어·기간별 트렌딩 저장소, 별 수 | 공식 API가 없어 페이지 구조 변경 시 실패할 수 있음 |
| stackoverflow | 질문 검색, 질문 본문, 득표순 상위 답변 5개 | 키 없이 하루 약 300회 제한, 댓글 |
| mdn | 문서 검색, 문서 본문(섹션별 텍스트) | 브라우저 호환성 표의 세부 수치, 대화형 예제 |
| npm | 패키지 검색, 최신 버전 메타데이터, 주간 다운로드 수 | README 전문, 과거 버전 목록 |
| hackernews | 글 검색, 첫 페이지, 글과 댓글(최대 80개) | 전체 댓글 트리 |
| lobsters | 인기·최신·태그별 글, 글과 댓글(최대 100개) | 사이트 내부 검색 |
| devto | 인기·최신 글, 글 전문(마크다운), 웹 검색 경유 검색 | 댓글, 사이트 내부 검색 순위 |
| geeknews | 최신 뉴스와 한국어 요약, 토픽 페이지 본문 | 사이트 내부 검색(웹 검색 경유), 전체 댓글 |
| yozm | 최신 글과 요약, 글 본문 | 사이트 내부 검색(웹 검색 경유) |
| medium | 태그·작성자·출판물의 최근 글(약 10개), 글 본문 | 유료 글 전문, 자체 도메인을 쓰는 출판물 |
| producthunt | 최근 등록된 제품과 한 줄 소개, 제품 페이지 | 득표 수, 순위, 댓글 |
| dribbble | 웹 검색으로 찾은 작업물 링크와 설명 | 이미지 자체, 사이트 내부 검색, 인기 순위 |
| youtube | 검색, 메타 정보, 자막 전문, 전사(키 필요) | 댓글, 자막이 없는 영상의 자막 |
| bluesky | 게시물 검색, 프로필, 최근 게시물, 답글 스레드(최대 80개) | 비공개·차단 계정, 전체 답글 |
| reddit | 공개 검색·본문·일부 댓글, 로그인 후 서브레딧 최신 글 | 전체 댓글 트리, 글쓰기 |
| twitter | 로그인 후 검색·프로필·타임라인·스레드 | 전체 답글, 글쓰기. 실험적 채널 |
| rss | 임의의 공개 피드의 최신 항목(항목당 본문 약 3,000자) | 사설망 주소, 인증이 필요한 피드, 80/443 이외의 포트 |
| web | 웹 검색(Exa), 임의 공개 페이지 본문(Jina Reader) | 로그인 뒤의 내용, 봇 차단 페이지 |

로그인 후의 기능을 설명할 때에는 "위 동작을 시도할 수 있다"고 표현하고, "로그인하면 모든 댓글을 볼 수 있다"처럼 단정하지 않습니다. 사용자가 로그인을 건너뛰면 이미 얻은 공개 결과를 그대로 전달합니다.
